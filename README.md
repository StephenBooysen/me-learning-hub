# Me Learning Hub

An intelligent learning platform that transforms web content into personalized study materials using advanced learning techniques like spaced repetition, active recall, and interleaving.

## Features

- **Study Plan Generation** - Automatically generates spaced repetition schedules
- **Learning Modes** - Multiple interactive study modes for different learning styles
- **Progress Tracking** - Visual analytics and learning progress monitoring
- **Dashboard** - Central hub for managing projects and learning progress

## Getting Started

```bash
# Install dependencies
npm install

# Start the Electron application
npm run electron:dev
```

## Project Structure

- `electron/` - Main Electron application and backend
- `package.json` - Root project configuration
